# Scott Mackey

Building multi-purpose agentic systems so AI has durable context across different kinds of work.

**[Context Forge](https://github.com/srmackey/context-forge)** gives an AI client a local memory of one workspace: working files and sitting notes, stored as markdown.

**[Insitu](https://github.com/srmackey/insitu)** gives an AI client a vault of reusable guidance and composes the right piece for the project it is sitting in.

**[DevSpan](https://github.com/srmackey/dev-span)** gives an AI client durable engineering context across repositories: components, repos, tasks, and governance, stored as markdown and composed per task.

**[Envoy](https://github.com/srmackey/envoy)** gives an AI client a local bulletin: who belongs, what each one last published, and the mail notes between them.

**[Brain Forge](https://github.com/srmackey/brain-forge)** ships the conventions and skills for a personal knowledge vault, and it leaves the vault's contents with its owner.

Enterprise full-stack underneath (integrations, migrations, APIs). Denver area. [LinkedIn](https://www.linkedin.com/in/scottrmackey)
